# 使用方法

## 下载

```bash
git clone https://gitcode.com/huanghaoqi/hexdump.git
cd hexdump
```

## 编译

```bash
gcc hexdump.c -o hexdump
``` 

## 运行
* 测试
```bash
echo "hello" | ./hexdump
```
